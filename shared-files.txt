# Files the Prof Tool shares with the Kalulu game.

# tools/sync-shared.sh copies each one from kalulu-frontend/ into project/ at the
# same path, together with its .uid and .import sidecars when they exist. Keeping
# the paths identical is what lets the Prof Tool's scenes and the shared code
# refer to each other exactly as they do in the game.
#
# Never edit these files under project/: change them in Kalulu-Frontend, bump the
# kalulu-frontend submodule, and run tools/sync-shared.sh.
#
# Everything here must depend on nothing outside this list.
